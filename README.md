# Cloud-Based Student Assignment Submission & Feedback Portal

A cloud-oriented student assignment submission and feedback platform designed to demonstrate modern cloud computing concepts through a practical full-stack application.

## Project Status

🚧 Initial project setup

## Planned Features

- Student registration and login
- Teacher authentication
- Role-based authorization
- Assignment creation and management
- Assignment submission
- File upload and download
- Deadline management
- Resubmission
- Teacher grading
- Written feedback
- Student dashboard
- Teacher dashboard
- REST APIs
- Cloud database
- Cloud object storage
- Cloud deployment
- Security
- Automated testing
- Scalability
- Monitoring and logging

## Technology Stack

### Frontend

- React
- Vite
- JavaScript

### Backend

- Python
- FastAPI

### Database

- SQLite for local development
- Cloud database for deployment

### Storage

- Local storage for development
- Cloud object storage for deployment

## Project Objective

The objective is to build an industry-oriented cloud-based assignment management platform that allows students to submit assignments remotely while enabling teachers to securely review, grade, and provide feedback.
